## Routing

En cas de besoin d'un "bloc" partagé entre différentes pages (header, menu, etc.), on DEVRAIT utiliser une route "layout" : une route parente dont le composant affiche le bloc partagé et un `<Outlet />`, dans lequel s'affichent les routes enfants.

```jsx
import { Route, Routes } from 'react-router-dom';

<Routes>
  <Route path="/cart/:id/proceed" element={<CartDetail type="proceed" />} />
  <Route path="/cart/:id/refund" element={<CartDetail type="refund" />} />
</Routes>;

// highlight-next-line
function CartDetail({ type }) {
  return (
    <>
      <CartHeader />

      {/* highlight-start */}
      {type === 'proceed' && <CartProceed />}
      {type === 'refund' && <CartRefund />}
      {/* highlight-end */}
    </>
  );
}
```

import { Outlet, Route, Routes } from 'react-router-dom';

function CartLayout() {
  return (
    <>
      <CartHeader />

    </>

On PEUT aussi extraire tout le "sous-routeur" dans un composant spécifique quand le nombre de routes à gérer devient trop grand et que le module est autonome. La route parente se termine alors par `/*`, et le composant déclare ses propres `<Routes>` avec des chemins relatifs :

```jsx
import { Route, Routes } from 'react-router-dom';

<Routes>
  {/* highlight-next-line */}
  <Route path="/cart/:id/*" element={<CartRoutes />} />
</Routes>;

function CartRoutes() {
  return (
    <>
      <CartHeader />

      {/* highlight-start */}
      <Routes>
        <Route path="proceed" element={<CartProceed />} />
        <Route path="refund" element={<CartRefund />} />
      </Routes>
      {/* highlight-end */}
    </>
  );
}
```
